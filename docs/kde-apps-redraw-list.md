# KDE apps to redraw (2026-10-29)

The 239 KDE apps (from apps.kde.org) that KDE Modern Classic doesn't draw yet. For each: every icon name the app
is known by (collected from KDE's directory and Papirus's name links), so the redraw can answer all of them, and
where KDE's own icon is, to redraw from in the classic style. Where a KDE Classic (KDE 3) original exists, prefer it.

Breeze icons are LGPL-3.0-or-later like this theme. Apps' own icons carry their app's licence; we redraw, not copy.
Papirus is used here only as a list of names. "Papirus: generic" means Papirus just links that app to a generic
picture (worth considering for minor apps).

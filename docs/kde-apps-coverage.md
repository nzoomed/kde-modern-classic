# KDE apps: which have icons (2026-10-29)

Every app in KDE's directory (apps.kde.org, 281 apps) checked against KDE Modern Classic's own icons and
Papirus's. Matching tries each app's short name and its `org.kde.` name.

Apps Modern Classic doesn't draw fall back to the KDE Classic bitmap theme (`kdeclassic`) if the user has it
installed, then to Breeze. KDE 3/4-era apps (most games and education apps) often have a classic bitmap there;
apps newer than ~2014 never do. Run `check-app-icons.sh` to see which theme each installed app actually uses.

# Alternative designs kept on record

Not built into the theme. Swap one back in by pointing the theme's drawing at the `*_dark` function.

| File | Was used for | Function | Replaced |
|---|---|---|---|
| `list-add-dark.svg` | list-add, add, gtk-add, value-increase (+ -symbolic) | `dolphin.list_add_dark` | 2026-10-27, by the green plus badge |
| `list-remove-dark.svg` | list-remove, remove, value-decrease (+ -symbolic) | `shell.minus_dark` | 2026-10-27, by the red minus badge |

The dark glyphs nearly vanished on dark colour schemes (Breeze Dark menus and settings pages). If users prefer
them, a light-grey glyph with a dark outline was also mocked up as a middle ground.
| `document-share-nodes.svg` | document-share (the Share menu/button) | `apps2.share_nodes` | Not used yet: option B, kept in case the page-with-nodes Share icon (`apps2.share_document`, 2026-10-27) doesn't read well |

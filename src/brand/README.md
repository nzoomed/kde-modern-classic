# Official logos (optional)

The generator never draws brand logos. A few file types look best with their project's own logo,
and some projects publish theirs under a free licence. Download the official file yourself, save
it here under the name below, and rebuild (`make build`).
Without the file, those types keep the generic emblem.

| File to save here | Where to get it | Licence | Used for |
|---|---|---|---|
| `debian-openlogo-nd.svg` | `openlogo-nd.svg` from https://www.debian.org/logos/ | LGPL-3+ or CC BY-SA 3.0 | `.deb` packages |

If you publish a theme that includes one, credit it in the theme's licence notes, e.g.
"Debian Open Use Logo, Copyright (c) 1999 Software in the Public Interest, Inc., LGPL-3+".
